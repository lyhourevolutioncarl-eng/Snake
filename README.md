Snake Game Description: This project is a 2D Snake game developed using JavaFX and the FXGL. The game runs on a grid system where the player controls a snake that moves continuously in one direction. The player uses the arrow keys to change the direction of the snake. The main goal is to eat the red food that appears randomly on the screen. Every time the snake eats food, its length increases and the player’s score goes up. The game becomes more challenging when the snake grows longer because it is harder to avoid collisions. The game will end if the snake hits the walls or collides with its own body. When the game is over, a Game Over screen is displayed with the final score and a message. The player can press ENTER to restart and play again without restarting the program.

How to control the game: Arrow key to move snake. Enter key to start over.

Major features: Grid-based movement. The food is generated randomly. A score is kept for each player. Collision detection is performed. Ability to restart the game from the point of the last collision. Simple and user-friendly design
